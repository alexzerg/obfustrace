# Nutrient DWS Integration

Micro-Embassy uses a server-only Next.js Route Handler to forward a temporary upload to Nutrient Document Web Services. The application does not persist the uploaded file.

## Configuration

Set the following environment variable locally and in Vercel:

```text
NUTRIENT_DWS_API_KEY=
```

Never prefix the variable with `NEXT_PUBLIC_`. The key must remain available only to the server-side Route Handler.

## API contract

- Readiness: `GET /api/documents/extract`
- Extraction: `POST /api/documents/extract`
- Multipart field: `document`
- Accepted types: PDF, JPEG, PNG, WebP
- Maximum size: 10 MB
- Upstream operation: `POST https://api.nutrient.io/build`
- Output: JSON content with key-value pairs, plain text, and structured text

Without an API key, the POST route returns HTTP 503 with `NUTRIENT_NOT_CONFIGURED`. It never substitutes fixture output for a sponsor API result.

## Synthetic evidence kit

`public/samples/maya-passport.pdf`, `maya-flight-itinerary.pdf`, and `maya-hotel-confirmation.pdf` are generated by `scripts/generate-evidence-kit.mjs`. Each file is prominently marked as invalid, contains no real personal information, and intentionally includes only facts appropriate to that source.
